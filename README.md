## Master Voyage System 
Company: DFDS
Architected and delivered the frontend of the Master Voyage System (MVS) within the Next.js monorepo of DFDS's next-gen Control Tower platform. Built on the Next.js App Router with Tailwind CSS styling, I engineered a high-performance hybrid rendering model for complex voyage creation workflows. To optimize client-side hydration and eliminate API fetch waterfalls, I designed dynamic form components that preload configuration metadata and select options on the server while maintaining interactive states on the client. Secured the application's core transactional logic by implementing robust unit testing coverage utilizing Vitest.
